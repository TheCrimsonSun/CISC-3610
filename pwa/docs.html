Touhou Overview

This document describes the placeholder PWA template structure and how to customize it for your own app.

Core Files

  • index.html - Main app shell and app content.
  • style.css - App styling and layout.
  • script.js - Install prompt and service worker registration.
  • manifest.webmanifest - PWA metadata, icons, and display settings.
  • sw.js - Service worker for offline caching.
