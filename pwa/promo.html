Gensokyo Archive

An interactive Touhou Project character encyclopedia. Explore, listen, and learn — installable and offline-ready.

Features

📖

Character Encyclopedia

Browse detailed profiles dynamically loaded from a JSON file — no page reloads.

🔊

Audio Narration

Listen to each character description via audio file or built-in text-to-speech.

📱

Installable PWA

Install on any device directly from the browser — no app store required.

🌐

Works Offline

A service worker caches the app so it's available without internet after first load.

⌨️

Keyboard Shortcuts

Arrow keys to navigate, spacebar to play/stop — fully keyboard accessible.

📂

JSON-Powered

All content lives in data.json — swap in any dataset without touching the code.

How to Install

1

Open this page in Chrome or Edge

The Install button above will light up automatically when your browser is ready.

2

Click "📥 Install App"

A browser dialog will appear — click Install to confirm.

3

On iOS Safari

Tap the Share icon → "Add to Home Screen" → "Add". (iOS does not show an install button.)

4

Use it offline

Once installed, the app works without an internet connection from your home screen or desktop.
