Gensokyo Archive

An interactive Touhou Project character encyclopedia — explore, listen, and learn about the residents of Gensokyo.

⛩ Launch the App

Features

📖

Character Encyclopedia

Browse detailed profiles of Touhou characters, including their abilities, species, and lore.

🔊

Audio Narration

Listen to each character's description read aloud using the Web Speech API — perfect for hands-free learning.

📱

Installable PWA

Install directly on your phone or desktop and use the app offline — no app store required.

⌨️

Keyboard Navigation

Use arrow keys to flip through characters and spacebar to play/stop audio.

📂

JSON-Powered

All content is stored in a simple JSON file — easy to edit or expand with new characters.

🌐

Works Offline

A service worker caches the app so it's available even without an internet connection.

How to Install

1

Open the app in your browser

Visit the hosted URL in Chrome, Edge, or Safari on any device.

2

Look for the install prompt

A banner will appear at the top of the app. Click Install.

3

On mobile (iOS Safari)

Tap the Share icon → "Add to Home Screen" → "Add".

4

Launch from your home screen

The app runs in standalone mode with offline support. No internet needed after first load.
