The data.json File

All content is driven by data.json. The app reads it on startup and builds the menu and cards automatically. No changes to HTML or JavaScript are needed when adding new characters.

Top-level fields

FieldTypeDescription
appNamestringApp name (display only)
descriptionstringShort description (display only)
user.namestringUsername shown in the sidebar footer
user.progressarrayReserved for tracking visited topics
user.preferences.volumenumberAudio volume 0.0–1.0
topicsarrayArray of topic/character objects

Topic object fields

FieldTypeRequiredDescription
idstring✅Unique identifier e.g. "topic6"
titlestring✅Character/topic name shown in menu and card
categorystring—Species or type label (shown in small text)
textstring✅Full description shown in the card
imagestring—Path to image file e.g. "images/char.png"
audiostring—Path to audio file e.g. "audio/char.mp3". Leave "" to use TTS.
audioTextstring—Text read aloud by TTS when no audio file is set. Falls back to text if omitted.

How to Add a New Character

  1. Open data.json in any text editor.
  2. Copy an existing object from the topics array.
  3. Paste it at the end of the array (before the closing ]), add a comma after the previous entry.
  4. Update all fields: give it a new unique id, fill in the content.
  5. Add the image to the images/ folder.
  6. Optionally add an audio file to an audio/ folder and set the audio field.
  7. Save and reload the app.

Example — adding Reimu Hakurei

{
  "id": "topic6",
  "title": "Reimu Hakurei",
  "category": "Shrine Maiden",
  "text": "Reimu is the main protagonist of the Touhou series and the shrine maiden of the Hakurei Shrine. She has the innate power to float through barriers.",
  "image": "images/reimu.png",
  "audio": "",
  "audioText": "Reimu Hakurei is the legendary shrine maiden who resolves incidents across Gensokyo."
}
⚠️ Make sure your JSON is valid. A missing comma or extra bracket will prevent the app from loading. Use jsonlint.com to check.

Audio: File vs Text-to-Speech

The app checks for an audio file first. If audio is an empty string or missing, it falls back to the browser's Web Speech API using audioText. To use your own recordings:

  1. Create an audio/ folder in the project.
  2. Add your .mp3 or .ogg file there.
  3. Set "audio": "audio/yourfile.mp3" in the topic object.

Updating the App Icon

Replace icons/icon-192.png and icons/icon-512.png with your own square PNG images. Update manifest.json if you change filenames.

Updating the Service Worker Cache

When you add new files (images, audio), update the ASSETS array in sw.js to include them. Also increment the CACHE_NAME version string (e.g. v1 → v2) so the old cache is cleared on next load.

Deployment

The app must be hosted over HTTPS for PWA install and service workers to work. Recommended hosts: GitHub Pages, Netlify, or Vercel — all free and HTTPS by default.
