Gensokyo Archive — Touhou Character Encyclopedia PWA

What is Gensokyo Archive?

Gensokyo Archive is an interactive Progressive Web App (PWA) that lets you explore profiles of Touhou Project characters. Each character card includes a name, species category, a description, an image, and an audio narration. The app works offline once installed.

Features

📖 Character Encyclopedia — Browse detailed profiles loaded dynamically from a JSON data file.
🔊 Audio Narration — Each character can be read aloud. Uses a provided audio file if available, or falls back to your browser's built-in text-to-speech.
📱 Installable PWA — Install directly on your phone or desktop. No app store needed.
🌐 Offline Support — A service worker caches the app so it works without internet after the first load.
⌨️ Keyboard Navigation — Navigate between characters and control audio without a mouse.

How to Use

  1. Open the app in your browser. Select a character from the left sidebar menu.
  2. Read the character's description in the card on the right.
  3. Click ▶ Listen to hear the audio narration. Click ■ Stop to stop it.
  4. Use ← Prev and Next → buttons to move between characters.
  5. On mobile, tap the ☰ hamburger button (top-left) to open the menu.

Keyboard Shortcuts

→ Next character    ← Previous character    Space Play / Stop audio

How to Install

  1. Open the app in Chrome, Edge, or Safari.
  2. A banner appears at the top — click Install.
  3. On iOS Safari: Tap Share → "Add to Home Screen" → Add.
  4. The app will appear on your home screen or desktop and can be used offline.

Browser Compatibility

Best experience in Chrome and Edge. Firefox supports all features except the install prompt. Safari on iOS supports "Add to Home Screen" manually via the Share menu.

Running Locally

The app must be served over HTTP — not opened directly as a file. If you have Python installed:

python -m http.server 8000 → then open http://localhost:8000
