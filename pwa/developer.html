PWA Template Developer Notes

Instructions for customizing the blank Progressive Web App starter.

How to customize this template

Replace the placeholder content in the core files to build your own PWA:

  1. Edit index.html to add the app content and structure.
  2. Update style.css for your own styling and layout.
  3. Modify script.js to add app behavior and data handling.
  4. Edit manifest.webmanifest to set the app name, colors, and icons.
  5. Adjust sw.js to cache the files your app needs offline.

Developer notes

This template includes install prompt support and a service worker registration. Add your own JSON data or app logic where needed.

App page: index.html Service worker: sw.js
