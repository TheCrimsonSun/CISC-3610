02 Responsive Breakpoints

Breakpoints control layout at different viewport widths. Stack them to build fully responsive grids.

xs <576px · sm ≥576px · md ≥768px · lg ≥992px · xl ≥1200px · xxl ≥1400px

→ col-12 col-sm-6 col-lg-3: 1 per row on mobile, 2 on sm, 4 on lg

A 12 / sm-6 / lg-3
B 12 / sm-6 / lg-3
C 12 / sm-6 / lg-3
D 12 / sm-6 / lg-3

→ col-12 col-md-4 sidebar + col-12 col-md-8 main: stacked on mobile, side-by-side on md+

Sidebar col-12 col-md-4
Main Content col-12 col-md-8

06 Order Utilities

order-N reorders columns visually without changing DOM order — handy for responsive rearrangement.

A DOM: 1st · order-3 displays 3rd
B DOM: 2nd · order-1 displays 1st
C DOM: 3rd · order-2 displays 2nd
